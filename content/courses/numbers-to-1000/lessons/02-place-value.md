# ערך המקום

במספר תלת־ספרתי יש שלוש ספרות, ולכל אחת יש מקום משלה:

- **מאות** בצד שמאל,
- **עשרות** באמצע,
- **יחידות** בצד ימין.

אותה ספרה שווה דברים שונים לפי המקום שבו היא עומדת. זה **ערך המקום**.

```scene
type: blocks
steps:
  - text: נבנה את 345. קודם 3 מאות.
    hundreds: 3
    label: "300"
  - text: אחר כך 4 עשרות.
    hundreds: 3
    tens: 4
    label: "300 + 40"
  - text: ובסוף 5 יחידות. ביחד, `300 + 40 + 5 = 345`.
    hundreds: 3
    tens: 4
    ones: 5
    label: "300 + 40 + 5 = 345"
```

## אותה ספרה, ערך אחר

במספר `444` כל הספרות הן 4, אבל כל אחת שווה משהו אחר: `400 + 40 + 4`. ה־4 השמאלית שווה פי 100 מהימנית!

## האפס שומר מקום

```scene
type: blocks
steps:
  - text: נבנה את 305. יש 3 מאות.
    hundreds: 3
    label: "300"
  - text: אין אף עשרת. אבל אי אפשר פשוט לדלג! כותבים `0` במקום העשרות.
    hundreds: 3
    label: "3 0 ?"
  - text: ועוד 5 יחידות. המספר הוא 305, ולא 35.
    hundreds: 3
    ones: 5
    label: "305 = 300 + 5"
  - text: בלי האפס היינו כותבים 35, מספר קטן בהרבה. רק 3 עשרות ו־5 יחידות.
    tens: 3
    ones: 5
    label: "35 ≠ 305"
```

> 📜 סיפור: לרומאים לא היה אפס, ולכן הם כתבו מספרים באותיות: 305 היה CCCV. חשבון כזה היה ממש קשה. השיטה שלנו, עם ערך המקום והאפס, הגיעה מהודו לפני כ־1,500 שנה, עברה דרך הערבים, והגיעה לאירופה רק לפני כ־800 שנה.

## לסיכום

- במספר תלת־ספרתי: מאות, עשרות, יחידות.
- `345 = 300 + 40 + 5`.
- כשאין עשרות או יחידות, כותבים `0` כדי לשמור על המקום.
