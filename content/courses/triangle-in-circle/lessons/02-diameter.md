# משולש על קוטר: זווית ישרה

מה קורה כשאחת הצלעות של המשולש החסום היא **קוטר**, כלומר עוברת דרך המרכז? מתברר שאז המשולש תמיד ישר זווית. זה אחד המשפטים הכי שימושיים בגיאומטריה של המעגל.

```scene
type: circle
points: { A: 180, B: 0, C: 60 }
lines: [AB, BC, CA]
steps:
  - text: הצלע `AB` עוברת דרך המרכז `O`, ולכן היא **קוטר**.
    hot: [AB]
  - text: נמדוד את הזווית שמול הקוטר, `ACB`. היא `90°`, זווית ישרה.
    hot: [AB]
    angles: [{ a: ACB, hot: true }]
  - text: נזיז את `C` על המעגל.
    at: { C: 125 }
    hot: [AB]
    angles: [{ a: ACB, hot: true }, CAB, ABC]
  - text: עד כמעט הקצה. שתי הזוויות האחרות משתנות, אבל `ACB` נשארת `90°` כל הזמן.
    at: { C: 165 }
    hot: [AB]
    angles: [{ a: ACB, hot: true }, CAB, ABC]
  - text: גם בחצי התחתון של המעגל, אותו דבר.
    at: { C: 250 }
    hot: [AB]
    angles: [{ a: ACB, hot: true }, CAB, ABC]
```

## הכלל

> **זווית היקפית שנשענת על קוטר היא זווית ישרה (`90°`).**

למה? הזווית המרכזית שנשענת על הקוטר היא `AOB`, והיא זווית שטוחה: `180°`. הזווית ההיקפית היא חצי ממנה, `180 ÷ 2 = 90`.

## עוד הוכחה, בלי הכלל מהשיעור הקודם

```scene
type: circle
points: { A: 180, B: 0, C: 60 }
lines: [AB, BC, CA, OC]
steps:
  - text: "`OA`, `OB` ו־`OC` הם כולם רדיוסים, ולכן הם שווים."
    marks: [OA, OB, OC]
  - text: המשולש `OAC` שווה שוקיים, ולכן זוויות הבסיס שלו שוות. נקרא להן `x`.
    marks: [OA, OC]
    fill: [OAC]
    angles: [{ a: OAC, label: x }, { a: OCA, label: x }]
  - text: גם המשולש `OBC` שווה שוקיים. נקרא לזוויות הבסיס שלו `y`.
    marks: [OB, OC]
    fill: [OBC]
    angles: [{ a: OAC, label: x }, { a: OCA, label: x }, { a: OBC, label: y }, { a: OCB, label: y }]
  - text: "סכום הזוויות במשולש `ABC` הוא `180°`: `x + (x + y) + y = 180`. כלומר `2x + 2y = 180`, ולכן `x + y = 90`. והזווית `ACB` היא בדיוק `x + y`!"
    angles: [{ a: OAC, label: x }, { a: OBC, label: y }, { a: ACB, label: "x + y = 90°", hot: true }]
    label: "2x + 2y = 180 → x + y = 90"
```

## וגם בכיוון ההפוך

אם משולש הוא ישר זווית, היתר שלו הוא קוטר של המעגל החוסם. לכן:

- **מרכז המעגל החוסם הוא אמצע היתר.**
- **הרדיוס הוא חצי מהיתר.**

דוגמה: במשולש ישר זווית הניצבים הם `6` ו־`8`. לפי משפט פיתגורס היתר הוא `10`, ולכן הרדיוס של המעגל החוסם הוא `5`.

> 📜 סיפור: המשפט הזה נקרא על שם **תאלס** מהעיר מילטוס, שחי לפני כ־2,600 שנה. מספרים שכשגילה אותו הוא שמח כל כך, שהקריב שור לאלים. תאלס נחשב לאחד הראשונים שלא הסתפקו ב"ככה זה עובד" ודרשו **הוכחה**.

> 🛒 בחיים: איך מוצאים את המרכז של צלחת עגולה? נגר משתמש בזווית ישרה (גונייה). שמים את הפינה של הגונייה על השפה של הצלחת, ומסמנים איפה שתי הצלעות שלה חוצות את השפה. הקו בין שתי הנקודות הוא קוטר! עושים את זה פעמיים, ובמקום שבו שני הקטרים נחתכים, נמצא המרכז.

```scene
type: circle
points: { A: 200, B: 20, C: 110 }
center: false
steps:
  - text: שמים את פינת הגונייה (זווית ישרה) על השפה, בנקודה `C`. הצלעות חוצות את השפה ב־`A` וב־`B`.
    lines: [CA, CB]
    angles: [{ a: ACB, hot: true }]
  - text: לפי תאלס, `AB` הוא קוטר. מסמנים אותו.
    lines: [CA, CB]
    hot: [AB]
    angles: [ACB]
  - text: מזיזים את הגונייה למקום אחר ועושים את זה שוב, ומקבלים קוטר שני, `DE`.
    at: { D: 255, E: 75, F: 330 }
    lines: [FD, FE]
    hot: [AB, DE]
    angles: [{ a: DFE, hot: true }]
  - text: המרכז נמצא בדיוק איפה ששני הקטרים נחתכים.
    at: { D: 255, E: 75, F: 330 }
    hot: [AB, DE]
    center: true
```

## לסיכום

- זווית היקפית שנשענת על קוטר היא `90°`.
- במשולש ישר זווית, היתר הוא קוטר של המעגל החוסם, והרדיוס הוא חצי מהיתר.
