# עשרות ויחידות

בכל מספר דו־ספרתי יש שתי ספרות, ולכל אחת יש תפקיד:

- הספרה **השמאלית** סופרת **עשרות**.
- הספרה **הימנית** סופרת **יחידות**.

```scene
type: blocks
steps:
  - text: נבנה את המספר 34. קודם 3 עשרות.
    tens: 3
    label: "30"
  - text: עכשיו מוסיפים 4 יחידות. יש 3 עשרות ו־4 יחידות.
    tens: 3
    ones: 4
    label: "34 = 30 + 4"
  - text: ומה אם מחליפים את הספרות? ב־43 יש **4 עשרות** ו־3 יחידות.
    tens: 4
    ones: 3
    label: "43 = 40 + 3"
  - text: אותן ספרות, אבל מספר אחר לגמרי. 43 גדול מ־34, כי יש בו יותר עשרות.
    tens: 4
    ones: 3
    label: "43 > 34"
```

## כשאין יחידות

```scene
type: blocks
steps:
  - text: במספר 70 יש 7 עשרות.
    tens: 7
    label: "70"
  - text: אין אף יחידה, ולכן הספרה הימנית היא `0`.
    tens: 7
    label: "70 = 70 + 0"
```

## לסיכום

- במספר `58` יש 5 עשרות ו־8 יחידות: `50 + 8`.
- הספרה `0` שומרת על המקום כשאין יחידות: `70`.
