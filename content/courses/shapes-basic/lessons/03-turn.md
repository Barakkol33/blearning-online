# אותה צורה מכל כיוון

> 💡 אם מסובבים ריבוע, האם הוא עדיין ריבוע?

הרבה ילדים חושבים שריבוע מסובב הוא כבר "צורה אחרת". אבל צורה לא משתנה כשמסובבים אותה. מה שקובע הוא **כמה צלעות** יש לה ו**איך הן נראות**.

```scene
type: shapes
steps:
  - text: זה ריבוע רגיל.
    shapes: [square]
    names: true
  - text: סובבנו אותו. נראה כמו יהלום, נכון?
    shapes: [square, square-tilted]
    names: true
  - text: נספור צלעות. עדיין 4 צלעות שוות. זה עדיין **ריבוע**.
    shapes: [square, square-tilted]
    show: sides
    names: true
```

## גם משולש יכול להיראות אחרת

משולש הוא **כל** צורה סגורה עם 3 צלעות ישרות, גם אם הוא נמוך ורחב או עקום.

```scene
type: shapes
steps:
  - text: זה משולש שאנחנו רגילים לראות.
    shapes: [triangle]
    names: true
  - text: וגם זה משולש, אפילו שהוא נראה אחרת.
    shapes: [triangle, triangle-odd]
    names: true
  - text: לשניהם 3 פינות, ולכן שניהם משולשים.
    shapes: [triangle, triangle-odd]
    show: corners
    names: true
```

> 📜 סיפור: המילה **גיאומטריה** באה מיוונית ופירושה "מדידת אדמה". לפי הסיפורים, במצרים העתיקה נהר הנילוס הציף כל שנה את השדות ומחק את הגבולות ביניהם, ומודדים היו צריכים לסמן אותם מחדש בעזרת צורות ומדידות.

## לסיכום

- צורה נשארת אותה צורה גם כשמסובבים אותה.
- כדי לדעת איזו צורה זו, סופרים צלעות ובודקים אותן.
- בכיתות הבאות נלמד על עוד הרבה צורות, ונמדוד אותן.
