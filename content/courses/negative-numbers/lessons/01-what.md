# מהם מספרים שליליים?

בחורף, על פסגת החרמון, הטמפרטורה יכולה לרדת מתחת לאפס. כשהחזאי אומר "מינוס 3 מעלות", הוא מתכוון למספר `-3`: שלוש מעלות **מתחת** לאפס.

מספרים כאלה נקראים **מספרים שליליים**. כותבים אותם עם סימן מינוס לפניהם.

## ציר המספרים

הדרך הכי נוחה לדמיין מספרים היא **ציר המספרים**: קו ישר שהאפס נמצא באמצע שלו.

- המספרים **החיוביים** (`1, 2, 3…`) נמצאים מימין לאפס.
- המספרים **השליליים** (`-1, -2, -3…`) נמצאים משמאל לאפס.

לחצו על "הבא" (או על הציור) כדי לראות:

```scene
type: number-line
range: [-6, 6]
steps:
  - text: זה ציר המספרים. האפס באמצע, והצפרדע שלנו עומדת עליו.
    marker: 0
    points: [0]
  - text: מימין לאפס נמצאים המספרים **החיוביים**.
    points: [1, 2, 3, 4, 5, 6]
  - text: משמאל לאפס נמצאים המספרים **השליליים**.
    points: [-1, -2, -3, -4, -5, -6]
  - text: הצפרדע קופצת 3 קפיצות שמאלה ונוחתת על `-3`.
    marker: -3
    arrow: [0, -3]
  - text: המספרים `3` ו־`-3` נמצאים באותו מרחק מהאפס, אבל בצדדים הפוכים. קוראים להם **מספרים נגדיים**.
    points: [-3, 3]
    label: "−3 ↔ 3"
```

## מי גדול יותר?

על ציר המספרים יש כלל אחד פשוט: **מספר שנמצא ימינה יותר הוא גדול יותר**.

לכן `-1` גדול מ־`-5`. זה מתאים גם לטמפרטורה: ב־`-5` מעלות קר יותר מאשר ב־`-1` מעלות.

```scene
type: number-line
range: [-6, 2]
steps:
  - text: נשווה בין `-5` לבין `-1`.
    points: [-5, -1]
  - text: הצפרדע מתחילה ב־`-5`.
    points: [-5, -1]
    marker: -5
  - text: כדי להגיע ל־`-1` היא צריכה לקפוץ **ימינה**, ולכן `-1` הוא הגדול מביניהם.
    points: [-5, -1]
    marker: -1
    arrow: [-5, -1]
    label: "−5 < −1"
```

## לסיכום

- מספר שלילי הוא מספר שקטן מאפס, וכותבים אותו עם סימן מינוס.
- על ציר המספרים, השליליים נמצאים משמאל לאפס.
- מספר ומספר נגדי לו נמצאים באותו מרחק מהאפס, בצדדים הפוכים.
- כל מספר גדול מכל מספר שנמצא משמאלו.
