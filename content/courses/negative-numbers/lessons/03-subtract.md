# חיסור מספרים שליליים

חיסור הוא הפעולה ההפוכה לחיבור. אם בחיבור קופצים לכיוון אחד, בחיסור קופצים לכיוון ההפוך.

## מחסרים מספר חיובי

מחסרים מספר חיובי: קופצים **שמאלה**. כך גם אפשר להגיע מתחת לאפס.

```scene
type: number-line
range: [-6, 6]
steps:
  - text: נחשב `1 - 4`. מתחילים ב־`1`.
    marker: 1
    points: [1]
  - text: מחסרים `4`, ולכן קופצים 4 קפיצות שמאלה.
    marker: -3
    arrow: [1, -3]
    points: [1]
  - text: הגענו ל־`-3`.
    marker: -3
    arrow: [1, -3]
    points: [1, -3]
    label: "1 − 4 = −3"
```

## מחסרים מספר שלילי

זה החלק המפתיע. כשמוסיפים `-3`, קופצים שמאלה. החיסור הפוך לחיבור, ולכן כשמחסרים `-3`, קופצים **ימינה**.

```scene
type: number-line
range: [-6, 6]
steps:
  - text: נחשב `2 - (-3)`. מתחילים ב־`2`.
    marker: 2
    points: [2]
  - text: אילו היינו **מוסיפים** `-3`, היינו קופצים 3 קפיצות שמאלה, עד `-1`.
    marker: 2
    arrow: [2, -1]
    points: [2]
    label: "2 + (−3) = −1"
  - text: אבל אנחנו **מחסרים** `-3`, ולכן עושים בדיוק את ההפך: 3 קפיצות ימינה.
    marker: 5
    arrow: [2, 5]
    points: [2]
  - text: הגענו ל־`5`.
    marker: 5
    arrow: [2, 5]
    points: [2, 5]
    label: "2 − (−3) = 5"
```

מכאן הכלל: **חיסור של מספר שלילי זהה לחיבור של המספר הנגדי לו.** לדוגמה, `2 - (-3)` שווה ל־`2 + 3`.

## לסיכום

- מחסרים מספר חיובי: זזים שמאלה.
- מחסרים מספר שלילי: זזים ימינה.
- "מינוס של מינוס" הופך לפלוס: `a - (-b) = a + b`.
