# אורך קטע: מפיתגורס לנוסחה

> 💡 השיעור משתמש ב: מערכת צירים, משפט פיתגורס, וריבוע ושורש (`(-3)² = 9`, `√25 = 5`).

דנה עומדת בנקודה `(1, 1)` על מפת רחובות, ויובל בנקודה `(5, 4)`. כל משבצת היא קילומטר. אם דנה הולכת ברחובות, היא עוברת `4` ק"מ ימינה ו־`3` ק"מ למעלה: `7` ק"מ. אבל כמה הם רחוקים **בקו אווירי**? נחשו, ואז נבדוק.

## תזכורת: נקודה במערכת צירים

לכל נקודה יש שני שיעורים, `(x, y)`. קודם `x`: כמה ימינה (או שמאלה, אם הוא שלילי). אחר כך `y`: כמה למעלה (או למטה).

```scene
type: axes
x: [-1, 7]
y: [-1, 5]
points: { A: [1, 1], B: [5, 4] }
steps:
  - text: הנקודה `B(5, 4)`. מהראשית, `5` ימינה...
    show: [B]
    proj: [B]
  - text: ...ו־`4` למעלה. הסדר חשוב: `(4, 5)` היא נקודה אחרת.
    show: [A, B]
    proj: [B]
```

## ברחובות או בקו אווירי?

```scene
type: axes
x: [-1, 7]
y: [-1, 5]
points: { A: [1, 1], B: [5, 4] }
steps:
  - text: דנה ב־`A`, יובל ב־`B`.
  - text: ברחובות, `4` ימינה ו־`3` למעלה. ביחד `7` ק"מ.
    legs: [AB]
    label: "4 + 3 = 7"
  - text: הקו האווירי הוא הקטע `AB`. הוא **היתר** של משולש ישר זווית, שהניצבים שלו `4` ו־`3`.
    legs: [AB]
    hot: [AB]
  - text: לפי פיתגורס, `AB² = 4² + 3² = 16 + 9 = 25`, ולכן `AB = 5`. רק `5` ק"מ, לא `7`.
    legs: [AB]
    hot: [AB]
    sides: { AB: "5" }
    label: "AB = √(4² + 3²) = 5"
```

נזכיר את **משפט פיתגורס**: במשולש ישר זווית, אם הניצבים `a` ו־`b` והיתר `c`, אז `a² + b² = c²`.

## הנוסחה

הניצב האופקי הוא ההפרש בין שיעורי ה־`x`, והניצב האנכי הוא ההפרש בין שיעורי ה־`y`. מכאן הנוסחה:

> **אורך הקטע** בין `A(x₁, y₁)` ל־`B(x₂, y₂)`:
>
> ‏`AB = √((x₂ - x₁)² + (y₂ - y₁)²)`

זו לא נוסחה חדשה לשנן. זה פיתגורס. שכחתם אותה? ציירו את המשולש.

## דוגמה עם מספרים שליליים

מה האורך של הקטע בין `A(-2, 3)` ל־`B(4, -5)`? נחשו קודם: בערך כמה?

```scene
type: axes
x: [-3, 5]
y: [-6, 4]
points: { A: [-2, 3], B: [4, -5] }
steps:
  - text: מציירים את הקטע. הוא אלכסוני, ולכן נחפש משולש ישר זווית.
    lines: [AB]
    label: AB = ?
  - text: "הניצב האופקי: `4 - (-2) = 6`. חיסור של שלילי הוא חיבור."
    lines: [AB]
    legs: [{ s: AB, dx: "4 − (−2) = 6" }]
  - text: "הניצב האנכי: `-5 - 3 = -8`. הסימן אומר שירדנו למטה."
    lines: [AB]
    legs: [{ s: AB, dx: "6", dy: "−5 − 3 = −8" }]
  - text: "מעלים בריבוע: `6² = 36`, ו־`(-8)² = 64`. ריבוע של שלילי הוא **חיובי**."
    hot: [AB]
    legs: [{ s: AB, dx: "6", dy: "8" }]
    label: "AB² = 36 + 64 = 100"
  - text: ולכן `AB = √100 = 10`.
    hot: [AB]
    legs: [{ s: AB, dx: "6", dy: "8" }]
    sides: { AB: "10" }
    label: AB = 10
```

כך כותבים את זה בבגרות, עם כל צעד ההצבה:

‏`AB = √((4 - (-2))² + (-5 - 3)²) = √(6² + (-8)²) = √(36 + 64) = √100 = 10`

> 💡 למה הסדר לא משנה? אם נחסר הפוך, `-2 - 4 = -6` ו־`3 - (-5) = 8`. אבל `(-6)² = 6²` ו־`8² = (-8)²`. הריבוע "מוחק" את הסימן, ולכן `AB = BA`.

## מקרים מיוחדים

- **קטע אופקי** (אותו `y`): האורך הוא ההפרש בין שיעורי ה־`x`. בין `(-2, 3)` ל־`(5, 3)`: `5 - (-2) = 7`. הנוסחה נותנת אותו דבר, כי הניצב השני הוא `0`.
- **קטע אנכי** (אותו `x`): ההפרש בין שיעורי ה־`y`.
- **תשובה לא שלמה:** בין `(0, 0)` ל־`(2, 4)`: `√(4 + 16) = √20`. משאירים `√20`, או כותבים בערך `4.47`.

> 📜 סיפור: בשנות ה־30 של המאה ה־17, שני מתמטיקאים צרפתים, רנה דקארט ופייר דה פרמה, הגיעו כל אחד בנפרד לאותו רעיון: לתאר כל נקודה בעזרת מספרים, ולפתור בעיות גאומטריה בחשבון. דקארט פרסם את הרעיון בספר "הגאומטריה" ב־1637, ועל שמו נקראת מערכת הצירים "קרטזית".

> 🛒 בחיים: אפליקציות מפה מראות לפעמים שני מרחקים: "בקו אווירי" ו"בדרך". בעיר עם רחובות ישרים, הדרך היא `Δx + Δy`, והקו האווירי הוא היתר. היתר תמיד קצר יותר.

## לסיכום

- קטע אלכסוני הוא יתר של משולש ישר זווית, עם ניצבים `x₂ - x₁` ו־`y₂ - y₁`.
- ‏`AB = √((x₂ - x₁)² + (y₂ - y₁)²)`. בבגרות כותבים את ההצבה המלאה.
- ריבוע של שלילי הוא חיובי, ולכן סדר החיסור לא משנה.
- בשיעור הבא: לא כמה רחוק, אלא **איפה האמצע**.
