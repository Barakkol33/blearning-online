# אמצע קטע

> 💡 השיעור משתמש ב: נקודה במערכת צירים, וחיבור של מספרים שליליים.

דנה ב־`(1, 1)` ויובל ב־`(5, 4)` רוצים להיפגש **בדיוק באמצע הדרך**, כדי ששניהם ילכו אותו מרחק. איפה נקודת המפגש?

## על ציר אחד: ממוצע

על ציר המספרים, האמצע בין `1` ל־`5` הוא `3`: שני צעדים מכל צד. זה בדיוק הממוצע, `(1 + 5) / 2 = 3`. האמצע בין `1` ל־`4` הוא `(1 + 4) / 2 = 2.5`.

## במישור: ממוצע בכל ציר

```scene
type: axes
x: [-1, 7]
y: [-1, 5]
points: { A: [1, 1], B: [5, 4] }
steps:
  - text: הקטע `AB`. איפה האמצע? נחשו לפני שממשיכים.
    lines: [AB]
    label: M = ?
  - text: נסתכל על הצללים של הנקודות על הצירים. על ציר ה־`x` הם ב־`1` וב־`5`. על ציר ה־`y` ב־`1` וב־`4`.
    lines: [AB]
    proj: [A, B]
  - text: "האמצע על ציר ה־`x`: `(1 + 5) / 2 = 3`. על ציר ה־`y`: `(1 + 4) / 2 = 2.5`."
    at: { M: [3, 2.5] }
    lines: [AB]
    proj: [M]
    label: M(3, 2.5)
  - text: בדיקה. `M` על הקטע, והוא מחלק אותו לשני חלקים שווים, `AM = MB`.
    at: { M: [3, 2.5] }
    lines: [AB]
    marks: [AM, MB]
```

> **אמצע הקטע** בין `A(x₁, y₁)` ל־`B(x₂, y₂)`:
>
> ‏`M = ((x₁ + x₂) / 2, (y₁ + y₂) / 2)`

> 💡 אמצע הוא **נקודה**, ואורך הוא **מספר**. בנוסחת האמצע **מחברים** ומחלקים ב־2. בנוסחת המרחק מחסרים, מעלים בריבוע ומוציאים שורש. אל תערבבו.

## דוגמה עם שליליים

מה האמצע של הקטע בין `A(-3, 4)` ל־`B(5, -2)`?

‏`x_M = (-3 + 5) / 2 = 2 / 2 = 1`, ‏`y_M = (4 + (-2)) / 2 = 2 / 2 = 1`, ולכן `M(1, 1)`.

טעות נפוצה: לחשב חצי מההפרש, `(5 - (-3)) / 2 = 4`. זה **חצי מהמרחק** על ציר ה־`x`, לא המקום של האמצע.

## הפוך: האמצע נתון, איפה הקצה?

נתון `A(-1, 2)`, ו־`M(2, 0)` הוא אמצע הקטע `AB`. איפה `B`?

```scene
type: axes
x: [-2, 6]
y: [-3, 3]
points: { A: [-1, 2], M: [2, 0] }
steps:
  - text: נתונים הקצה `A` והאמצע `M`. איפה הקצה השני?
    lines: [AM]
  - text: מ־`A` ל־`M` זזים `3` ימינה ו־`2` למטה.
    lines: [AM]
    legs: [{ s: AM, dx: "+3", dy: "−2" }]
  - text: "`M` באמצע, ולכן מ־`M` ל־`B` זזים שוב **אותו צעד**: `3` ימינה ו־`2` למטה."
    at: { B: [5, -2] }
    lines: [AM, MB]
    legs: [{ s: AM, dx: "+3", dy: "−2" }, { s: MB, dx: "+3", dy: "−2" }]
  - text: "`B(5, -2)`. בדיקה: האמצע של `(-1, 2)` ו־`(5, -2)` הוא `(2, 0)`."
    at: { B: [5, -2] }
    hot: [AB]
    marks: [AM, MB]
    label: B(5, −2)
```

באלגברה, מציבים בנוסחת האמצע ופותרים:

‏`(-1 + x_B) / 2 = 2`, ולכן `x_B = 2 · 2 - (-1) = 5`. ‏`(2 + y_B) / 2 = 0`, ולכן `y_B = 2 · 0 - 2 = -2`.

> 💡 קיצור: `B = 2M - A`, בכל שיעור לחוד. טעות נפוצה: לחשב את הממוצע של `A` ו־`M`. זה נותן נקודה **בין** `A` ל־`M`, לא את הקצה.

> 🛒 בחיים: אפליקציות שמציעות "מקום מפגש באמצע" מחשבות בדיוק את זה: הממוצע של קווי האורך והממוצע של קווי הרוחב של שני האנשים (בערך, כי כדור הארץ עגול).

## לסיכום

- האמצע הוא ממוצע, בכל ציר לחוד: `M = ((x₁ + x₂) / 2, (y₁ + y₂) / 2)`.
- קצה מהאמצע: אותו צעד שוב, `B = 2M - A`.
- תמיד בודקים: האם `M` באמת בין `A` ל־`B`?
- בשיעור הבא: משתמשים באורכים ובאמצעים כדי לזהות משולשים ולהוכיח שמרובע הוא מקבילית.
