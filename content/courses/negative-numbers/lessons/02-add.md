# חיבור על ציר המספרים

בחיבור, הצפרדע מתחילה במספר הראשון וקופצת לפי המספר השני:

- מוסיפים מספר **חיובי**: קופצים **ימינה**.
- מוסיפים מספר **שלילי**: קופצים **שמאלה**.

## מוסיפים מספר חיובי

```scene
type: number-line
range: [-6, 6]
steps:
  - text: נחשב `2 + 3`. מתחילים ב־`2`.
    marker: 2
    points: [2]
  - text: מוסיפים `3`, שזה מספר חיובי, ולכן קופצים 3 קפיצות ימינה.
    marker: 5
    arrow: [2, 5]
    points: [2]
  - text: הגענו ל־`5`.
    marker: 5
    arrow: [2, 5]
    points: [2, 5]
    label: "2 + 3 = 5"
```

זה עובד גם כשמתחילים במספר שלילי:

```scene
type: number-line
range: [-6, 6]
steps:
  - text: נחשב `-4 + 6`. מתחילים ב־`-4`.
    marker: -4
    points: [-4]
  - text: קופצים 6 קפיצות ימינה, ועוברים את האפס בדרך.
    marker: 2
    arrow: [-4, 2]
    points: [-4]
  - text: הגענו ל־`2`.
    marker: 2
    arrow: [-4, 2]
    points: [-4, 2]
    label: "−4 + 6 = 2"
```

## מוסיפים מספר שלילי

כשמוסיפים מספר שלילי, הכיוון מתהפך: קופצים **שמאלה**.

אפשר לחשוב על זה ככסף: יש לכם 3 שקלים, ואתם חייבים לחבר שלכם 5 שקלים. אחרי שתחזירו את החוב, יחסרו לכם 2 שקלים, כלומר יהיו לכם `-2`.

```scene
type: number-line
range: [-6, 6]
steps:
  - text: נחשב `3 + (-5)`. מתחילים ב־`3`.
    marker: 3
    points: [3]
  - text: מוסיפים `-5`, שזה מספר שלילי, ולכן קופצים 5 קפיצות **שמאלה**.
    marker: -2
    arrow: [3, -2]
    points: [3]
  - text: הגענו ל־`-2`.
    marker: -2
    arrow: [3, -2]
    points: [3, -2]
    label: "3 + (−5) = −2"
```

## לסיכום

- חיבור מספר חיובי: זזים ימינה.
- חיבור מספר שלילי: זזים שמאלה.
- מספר ועוד המספר הנגדי לו תמיד שווה `0`, למשל `-7 + 7 = 0`.
