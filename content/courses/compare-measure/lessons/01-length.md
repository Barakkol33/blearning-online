# ארוך וקצר

> 💡 העיפרון שלך ארוך יותר מהמחק? איך אפשר לדעת בטוח?

כדי להשוות אורכים, שמים את הדברים **זה ליד זה** ובודקים מי מגיע רחוק יותר.

```scene
type: measure
steps:
  - text: יש לנו עיפרון ומברשת.
    bars:
      - { name: עיפרון, emoji: ✏️, len: 9 }
      - { name: מברשת, emoji: 🖌️, len: 6 }
  - text: שניהם מתחילים באותו מקום. העיפרון מגיע רחוק יותר, ולכן הוא **ארוך יותר**. המברשת **קצרה יותר**.
    bars:
      - { name: עיפרון, emoji: ✏️, len: 9 }
      - { name: מברשת, emoji: 🖌️, len: 6 }
    label: "העיפרון ארוך יותר"
```

## זהירות: מיישרים את ההתחלה!

```scene
type: measure
steps:
  - text: מי ארוך יותר עכשיו? המברשת נראית ארוכה, כי היא מתחילה רחוק יותר.
    bars:
      - { name: עיפרון, emoji: ✏️, len: 9 }
      - { name: מברשת, emoji: 🖌️, len: 6, offset: 5 }
  - text: מזיזים את המברשת כך ששניהם יתחילו באותו מקום. העיפרון עדיין ארוך יותר!
    bars:
      - { name: עיפרון, emoji: ✏️, len: 9 }
      - { name: מברשת, emoji: 🖌️, len: 6 }
    label: "תמיד מיישרים את ההתחלה"
```

## לסיכום

- כדי להשוות אורכים, מיישרים את ההתחלות ובודקים מי מגיע רחוק יותר.
- בשיעור הבא נמדוד בדיוק כמה ארוך כל דבר.
