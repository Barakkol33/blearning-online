# זווית מרכזית וזווית היקפית

כשכל שלושת הקודקודים של משולש נמצאים על מעגל, אומרים שהמשולש **חסום** במעגל, והמעגל **חוסם** את המשולש. בשיעור הזה נכיר שתי זוויות שנוצרות בתוך מעגל, ואת הקשר המפתיע ביניהן.

## כמה מילים לפני שמתחילים

- **מיתר**: קטע שמחבר שתי נקודות על המעגל. למשל `AB`.
- **קשת**: החלק של המעגל שבין שתי נקודות.
- **זווית מרכזית**: הקודקוד שלה במרכז המעגל, `O`, והשוקיים שלה הם רדיוסים.
- **זווית היקפית**: הקודקוד שלה על המעגל, והשוקיים שלה הם מיתרים.

כל זווית כזאת "נשענת" על קשת: הקשת שנמצאת בין השוקיים שלה.

```scene
type: circle
points: { A: 210, B: 330, C: 100 }
steps:
  - text: משולש `ABC` חסום במעגל שמרכזו `O`. כל הקודקודים שלו על המעגל.
    lines: [AB, BC, CA]
  - text: הזווית `ACB` היא **זווית היקפית**. הקודקוד שלה, `C`, נמצא על המעגל. היא נשענת על הקשת `AB` (בכתום).
    lines: [AC, BC]
    arc: [AB]
    angles: [{ a: ACB, label: "", hot: true }]
  - text: עכשיו נחבר את `A` ואת `B` למרכז. הזווית `AOB` היא **זווית מרכזית**, והיא נשענת על אותה קשת.
    lines: [AC, BC, OA, OB]
    arc: [AB]
    angles: [{ a: ACB, label: "" }, { a: AOB, label: "", hot: true }]
  - text: נמדוד את שתיהן. ההיקפית היא `60°`, והמרכזית `120°`. בדיוק פי 2!
    lines: [AC, BC, OA, OB]
    arc: [AB]
    angles: [ACB, AOB]
  - text: נזיז את `C` על המעגל. שימו לב לזווית ההיקפית.
    at: { C: 160 }
    lines: [AC, BC, OA, OB]
    arc: [AB]
    angles: [ACB, AOB]
  - text: ועכשיו לצד השני. היא עדיין `60°`! כל עוד `C` על אותה קשת גדולה, הזווית לא משתנה.
    at: { C: 25 }
    lines: [AC, BC, OA, OB]
    arc: [AB]
    angles: [ACB, AOB]
```

## הכלל

> **זווית היקפית שווה לחצי מהזווית המרכזית שנשענת על אותה קשת.**

ומזה יוצא עוד כלל, שראינו כשהזזנו את `C`: **זוויות היקפיות שנשענות על אותה קשת שוות זו לזו**.

דוגמה: אם הזווית המרכזית היא `80°`, כל זווית היקפית שנשענת על אותה קשת היא `80 ÷ 2 = 40°`.

## למה זה נכון?

זה לא קסם. אפשר להוכיח את זה רק בעזרת שני דברים שכבר מכירים: משולש שווה שוקיים, וזווית חיצונית של משולש (היא שווה לסכום שתי הזוויות במשולש שלא צמודות לה).

```scene
type: circle
points: { A: 200, B: 320, C: 90, D: 270 }
lines: [CA, CB]
steps:
  - text: נתחיל מהזווית ההיקפית `ACB`. נעביר קוטר מ־`C`, דרך המרכז `O`, עד הנקודה `D`.
    hot: [CD]
    angles: [{ a: ACB, label: "" }]
  - text: "`OA` ו־`OC` הם רדיוסים, ולכן הם שווים. המשולש `OAC` הוא שווה שוקיים."
    lines: [CD, OA]
    marks: [OA, OC]
    fill: [OAC]
  - text: במשולש שווה שוקיים זוויות הבסיס שוות. נקרא לכל אחת מהן `x`.
    lines: [CD, OA]
    marks: [OA, OC]
    fill: [OAC]
    angles: [{ a: OCA, label: x }, { a: OAC, label: x }]
  - text: הזווית `AOD` היא זווית חיצונית למשולש `OAC`. היא שווה לסכום שתי הזוויות שלא צמודות לה, `x + x = 2x`.
    lines: [CD, OA]
    marks: [OA, OC]
    fill: [OAC]
    angles: [{ a: OCA, label: x }, { a: OAC, label: x }, { a: AOD, label: 2x, hot: true }]
  - text: אותו דבר בצד השני. `OB` ו־`OC` רדיוסים, ולכן זוויות הבסיס שוות, `y`, והזווית החיצונית `BOD` היא `2y`.
    lines: [CD, OB]
    marks: [OB, OC]
    fill: [OBC]
    angles: [{ a: OCB, label: y }, { a: OBC, label: y }, { a: BOD, label: 2y, hot: true }]
  - text: "נחבר את שני הצדדים: ההיקפית היא `x + y`, והמרכזית היא `2x + 2y`. כלומר המרכזית כפולה מההיקפית."
    lines: [CD, OA, OB]
    angles: [{ a: OCA, label: x }, { a: OCB, label: y }, { a: AOD, label: 2x }, { a: BOD, label: 2y }]
    label: "AOB = 2x + 2y = 2 · ACB"
```

ההוכחה שראינו היא למקרה שבו המרכז `O` נמצא בתוך הזווית ההיקפית. כשהוא מחוצה לה, ההוכחה כמעט אותה הוכחה, רק עם חיסור במקום חיבור.

> 📜 סיפור: את ההוכחה הזאת כתב אוקלידס בספר "יסודות" לפני כ־2,300 שנה, ומלמדים אותה כמעט באותן מילים עד היום. "יסודות" היה ספר הלימוד במתמטיקה של העולם במשך יותר מאלפיים שנה.

> 🛒 בחיים: שחקן כדורגל עומד מול השער. אם השחקן זז על קשת של מעגל שעוברת דרך שני עמודי השער, השער "נראה" לו באותה זווית בדיוק, כי כל אלה זוויות היקפיות על אותה קשת. כך גם בבית קולנוע: בכל המושבים שעל קשת כזאת, המסך נראה באותה זווית.

## לסיכום

- זווית מרכזית: הקודקוד במרכז. זווית היקפית: הקודקוד על המעגל.
- היקפית = חצי ממרכזית שנשענת על אותה קשת.
- זוויות היקפיות שנשענות על אותה קשת שוות זו לזו.
