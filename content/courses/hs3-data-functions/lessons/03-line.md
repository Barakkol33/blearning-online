# גרף קו: שינוי לאורך זמן

> 🛒 בחיים: כמה מכוניות חשמליות חדשות נרשמו בעיר בכל שנה? (נתונים לדוגמה.)
>
> השאלה של היום: **מתי הייתה הקפיצה הגדולה?**

## קוראים את הגרף

בגרף קו, הציר האופקי הוא **הזמן**. כל נקודה היא שנה אחת. הקו מחבר בין השנים.

```scene
type: chart
kind: line
name: מכוניות
tick: 100
data: [["2020", 200], ["2021", 300], ["2022", 500], ["2023", 600], ["2024", 660]]
steps:
  - text: בשנת 2020 נרשמו 200 מכוניות.
    show: 1
    values: true
  - text: הקו עולה, שנה אחרי שנה.
    values: true
  - text: קו עולה פירושו שהמספר גדל. קו יורד, קטן. קו אופקי, לא משתנה.
    values: true
```

## מתי הייתה הקפיצה הגדולה?

הקפיצה הגדולה היא **ההפרש** הגדול בין שתי שנים. בגרף, זה **הקטע התלול** ביותר.

ההפרשים: `300 - 200 = 100`, `500 - 300 = 200`, `600 - 500 = 100`, `660 - 600 = 60`.

```scene
type: chart
kind: line
name: מכוניות
tick: 100
data: [["2020", 200], ["2021", 300], ["2022", 500], ["2023", 600], ["2024", 660]]
steps:
  - text: הקטע בין 2021 ל־2022 הוא התלול ביותר.
    values: true
    seg: 1
    hot: [1, 2]
    label: עלייה של 200
  - text: שימו לב, 2024 היא השנה עם הכי הרבה מכוניות, אבל לא עם הקפיצה הגדולה.
    values: true
    seg: 3
    hot: [3, 4]
    label: עלייה של 60 בלבד
```

התשובה לשאלה של היום: הקפיצה הגדולה הייתה **בין 2021 ל־2022**, עלייה של 200 מכוניות.

## שינוי באחוזים

לפעמים שואלים: "**בכמה אחוזים** עלה המספר?" מחלקים את ההפרש **בערך הישן**, ומכפילים ב־100.

```scene
type: chart
kind: line
name: מכוניות
tick: 100
data: [["2020", 200], ["2021", 300], ["2022", 500], ["2023", 600], ["2024", 660]]
steps:
  - text: מ־2020 ל־2021 עלה ב־100. הערך הישן 200.
    values: true
    seg: 0
    hot: [0, 1]
    label: 100 ÷ 200 · 100 = 50%
  - text: מ־2022 ל־2023 עלה גם ב־100. אבל הערך הישן 500.
    values: true
    seg: 2
    hot: [2, 3]
    label: 100 ÷ 500 · 100 = 20%
  - text: אותה עלייה של 100. פעם זה 50%, ופעם רק 20%.
    values: true
    seg: [0, 2]
    hot: [0, 1, 2, 3]
```

> 💡 תמיד מחלקים בערך **הישן**, של השנה המוקדמת. מ־500 ל־600: `100 ÷ 500`, ולא `100 ÷ 600`.

## ציר שמטעה

אותם נתונים בדיוק. מה משתנה כשהציר לא מתחיל ב־0?

```scene
type: chart
kind: line
name: מכוניות
data: [["2020", 200], ["2021", 300], ["2022", 500], ["2023", 600], ["2024", 660]]
steps:
  - text: הציר מתחיל ב־0. העלייה נראית סבירה.
    values: true
  - text: עכשיו הציר מתחיל ב־200. אותם מספרים, אבל הקו נראה תלול הרבה יותר.
    values: true
    min: 200
    label: הציר מתחיל ב־200!
```

לפני שמסיקים "עלייה ענקית", בודקים איפה מתחיל הציר.

> 💡 הגרף מראה רק את מה שכבר קרה. "ב־2025 יהיו בטוח 720" זו לא מסקנה מהגרף. אפשר רק לנחש.

## לסיכום

- קו עולה: גדל. קו יורד: קטן. הקטע התלול ביותר: השינוי הגדול ביותר.
- שינוי באחוזים: ההפרש ÷ הערך הישן × 100.
- אותו הפרש יכול להיות אחוז שונה.
- בודקים איפה מתחיל הציר, ולא מנבאים את העתיד בוודאות.
- בשיעור הבא: גרף שיש לו גם **כלל**, נוסחה.
