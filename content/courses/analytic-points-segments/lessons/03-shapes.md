# משולשים ומרובעים: סוג, היקף והוכחה

> 💡 השיעור משתמש ב: נוסחת המרחק, נוסחת האמצע, המשפט ההפוך לפיתגורס, ותכונות של מקבילית ומעוין.

יש לנו רק שיעורים של נקודות. אין סרגל ואין מד זווית. איך אפשר לדעת אם משולש הוא ישר זווית, או **להוכיח** שמרובע הוא מקבילית? מתברר שאורכים ואמצעים מספיקים.

## איזה משולש זה?

```scene
type: axes
x: [-1, 7]
y: [-1, 9]
points: { A: [1, 1], B: [5, 4], C: [2, 8] }
steps:
  - text: המשולש `ABC`. מה הסוג שלו? נחשו לפי הציור.
    lines: [AB, BC, CA]
  - text: "`AB² = (5 - 1)² + (4 - 1)² = 16 + 9 = 25`."
    lines: [BC, CA]
    hot: [AB]
    legs: [AB]
    sides: { AB: "AB²=25" }
  - text: "`BC² = (2 - 5)² + (8 - 4)² = 9 + 16 = 25`. אותו דבר! `AB = BC`."
    lines: [AB, CA]
    hot: [BC]
    legs: [BC]
    marks: [AB, BC]
    sides: { AB: "AB²=25", BC: "BC²=25" }
  - text: "`AC² = (2 - 1)² + (8 - 1)² = 1 + 49 = 50`."
    lines: [AB, BC]
    hot: [CA]
    marks: [AB, BC]
    sides: { AB: "AB²=25", BC: "BC²=25", CA: "AC²=50" }
  - text: "`25 + 25 = 50`, כלומר `AB² + BC² = AC²`. לפי המשפט ההפוך לפיתגורס, הזווית `B` ישרה."
    fill: [ABC]
    lines: [AB, BC, CA]
    marks: [AB, BC]
    right: [ABC]
    sides: { AB: "AB²=25", BC: "BC²=25", CA: "AC²=50" }
    label: 25 + 25 = 50
```

המשולש `ABC` הוא **ישר זווית ושווה שוקיים**.

> 💡 טריק: כדי להשוות אורכים, משווים את **הריבועים** שלהם. כך לא צריך להוציא שורש בכלל. גם המשפט ההפוך לפיתגורס עובד עם הריבועים.

**היקף** הוא סכום הצלעות. כאן: `5 + 5 + √50`, בערך `17.07`. כשצלע אופקית או אנכית, את האורך שלה סופרים בלי נוסחה.

## הוכחה: מקבילית ומעוין

שני משפטים מכיתה ט׳ שנשתמש בהם:

- מרובע שבו **האלכסונים חוצים זה את זה** הוא מקבילית. במערכת צירים: לשני האלכסונים יש **אותו אמצע**.
- מקבילית שבה **שתי צלעות סמוכות שוות** היא מעוין.

**שאלה:** נתון המרובע `ABCD`, עם `A(0, 0)`, `B(5, 0)`, `C(8, 4)`, `D(3, 4)`. הוכיחו ש־`ABCD` מעוין.

```scene
type: axes
x: [-1, 9]
y: [-1, 5]
points: { A: [0, 0], B: [5, 0], C: [8, 4], D: [3, 4] }
steps:
  - text: המרובע `ABCD`. האלכסונים שלו הם `AC` ו־`BD`, לא `AB` ו־`CD`.
    lines: [AB, BC, CD, DA]
  - text: "אמצע האלכסון `AC`: `((0 + 8) / 2, (0 + 4) / 2) = (4, 2)`."
    at: { M: [4, 2] }
    show: [A, B, C, D, M]
    lines: [AB, BC, CD, DA]
    dash: [AC]
    marks: [AM, MC]
  - text: "אמצע האלכסון `BD`: `((5 + 3) / 2, (0 + 4) / 2) = (4, 2)`. אותה נקודה! האלכסונים חוצים זה את זה, ולכן `ABCD` מקבילית."
    at: { M: [4, 2] }
    lines: [AB, BC, CD, DA]
    dash: [AC, BD]
    marks: [AM, MC]
    marks2: [BM, MD]
  - text: "שתי צלעות סמוכות: `AB = 5` (אופקית), ו־`AD = √(3² + 4²) = 5`. הן שוות, ולכן המקבילית היא מעוין."
    show: [A, B, C, D]
    coords: false
    fill: [ABCD]
    lines: [BC, CD]
    hot: [AB, DA]
    legs: [AD]
    sides: { AB: "5", DA: "5" }
    label: AB = AD = 5
```

**הוכחה לדוגמה.** בכל שורה טענה אחת, ולצידה הנימוק שלה:

| | טענה | נימוק |
|---|---|---|
| 1 | אמצע `AC` הוא `((0 + 8) / 2, (0 + 4) / 2) = (4, 2)` | נוסחת אמצע קטע |
| 2 | אמצע `BD` הוא `((5 + 3) / 2, (0 + 4) / 2) = (4, 2)` | נוסחת אמצע קטע |
| 3 | האלכסונים `AC` ו־`BD` חוצים זה את זה | יש להם אותו אמצע (שורות 1 ו־2) |
| 4 | ‏`ABCD` מקבילית | מרובע שבו האלכסונים חוצים זה את זה הוא מקבילית (שורה 3) |
| 5 | ‏`AB = √((5 - 0)² + (0 - 0)²) = √25 = 5` | נוסחת המרחק |
| 6 | ‏`AD = √((3 - 0)² + (4 - 0)²) = √25 = 5` | נוסחת המרחק |
| 7 | ‏`ABCD` מעוין | מקבילית שבה שתי צלעות סמוכות שוות היא מעוין (שורות 4, 5 ו־6) |

## מה **לא** מספיק

- "`AB = CD`, ולכן מקבילית": לא. גם בטרפז שווה שוקיים יש זוג צלעות שוות.
- "האלכסונים שווים, ולכן מעוין": לא. מקבילית עם אלכסונים שווים היא **מלבן**.
- תשובה בלי נימוק: בבגרות, טענה בלי נימוק לא מקבלת את מלוא הנקודות.

## לסיכום

- סוג משולש: משווים את ריבועי הצלעות. שניים שווים: שווה שוקיים. סכום שני הקטנים שווה לגדול: ישר זווית.
- היקף: סכום הצלעות.
- מקבילית: לאלכסונים אותו אמצע. מעוין: ועוד שתי צלעות סמוכות שוות.
- בהוכחה, כל טענה מקבלת נימוק.
- בקורס הבא: **ישרים**. השיפוע בנוי מאותם הפרשים, `Δy` ו־`Δx`.
