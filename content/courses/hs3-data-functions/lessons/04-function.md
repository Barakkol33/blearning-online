# פונקציה במילים, בטבלה, בגרף ובכלל

> 🛒 בחיים: נר באורך 12 ס״מ נשרף 2 ס״מ בכל שעה.
>
> השאלה של היום: **אחרי כמה שעות יישארו מהנר 5 ס״מ?**

השיעור הזה משתמש במשוואה (מעבירים אגפים) ובנקודה במערכת צירים, `(x, y)`.

## ארבע דרכים לספר אותו דבר

**במילים:** הנר מתחיל ב־12 ס״מ, וכל שעה הוא מתקצר ב־2.

**בטבלה:** בכל שעה מחסרים 2.

| זמן `t` (שעות) | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| אורך `L` (ס״מ) | 12 | 10 | 8 | 6 | 4 | 2 | 0 |

**בכלל (נוסחה):** האורך הוא 12, פחות 2 בכל שעה: `L = 12 - 2t`.

**בגרף:** כל עמודה בטבלה היא נקודה `(t, L)`. הציר האופקי (`x`) הוא הזמן `t`, והאנכי (`y`) הוא האורך `L`.

```scene
type: axes
x: [0, 7]
y: [-1, 12]
coords: false
points: { A: [0, 12], B: [1, 10], C: [2, 8], D: [3, 6], E: [4, 4], F: [5, 2], G: [6, 0] }
steps:
  - text: כל עמודה בטבלה היא נקודה. למשל `(0, 12)`: בהתחלה הנר 12 ס״מ.
    show: [A]
  - text: עוד נקודות מהטבלה, אחת לכל שעה.
    show: [A, B, C, D, E, F, G]
  - text: הנר נשרף כל הזמן, לא רק בשעות שלמות. לכן מחברים בקו.
    show: [A, B, C, D, E, F, G]
    lines: [AG]
```

**כלל** הוא הדרך הכי קצרה: הוא נותן את האורך בכל זמן, גם `t = 2.5`. זו **פונקציה**: לכל זמן יש אורך אחד.

## הצבה: נתון הזמן

כמה ס״מ יישארו אחרי 2.5 שעות? **מציבים** 2.5 במקום `t`:

- ‏`L = 12 - 2 · 2.5`
- ‏`L = 12 - 5`
- ‏`L = 7`. יישארו 7 ס״מ.

## משוואה: נתון האורך

עכשיו השאלה של היום. כאן נתון **האורך**, `L = 5`, ומחפשים את **הזמן**. כותבים משוואה:

- ‏`12 - 2t = 5`: מה שנתון.
- ‏`-2t = 5 - 12`: מעבירים את 12 לאגף השני.
- ‏`-2t = -7`
- ‏`t = 3.5`: מחלקים ב־`-2`.
- בדיקה: `12 - 2 · 3.5 = 12 - 7 = 5` ✔.

```scene
type: axes
x: [0, 7]
y: [-1, 12]
coords: false
points: { A: [0, 12], G: [6, 0] }
lines: [AG]
steps:
  - text: בגרף, יוצאים מ־5 בציר האנכי, עד הקו.
    at: { P: [3.5, 5] }
    show: [A, G, P]
    proj: [P]
    label: L = 5
  - text: ויורדים לציר האופקי. `t = 3.5` שעות.
    at: { P: [3.5, 5] }
    show: [A, G, P]
    proj: [P]
    label: t = 3.5
```

התשובה לשאלה של היום: אחרי **3.5 שעות**, שלוש שעות וחצי.

> 💡 מה קורה ב־`t = 8`? הכלל נותן `L = 12 - 16 = -4`. אבל לנר אין אורך שלילי. הוא נגמר כבר ב־`t = 6`. הכלל נכון רק בזמנים שיש להם משמעות: מ־0 עד 6.

## כשיש שתי תשובות

כדור נזרק למעלה. הגובה שלו (במטרים) אחרי `t` שניות: `h = 8t - 2t²`. **מתי הכדור בגובה 6 מטר?** נחשו לפני שממשיכים: פעם אחת, או יותר?

```scene
type: chart
kind: line
name: גובה (מ׳)
xName: זמן (שניות)
tick: 2
xEvery: 2
data: [["0", 0], ["0.5", 3.5], ["1", 6], ["1.5", 7.5], ["2", 8], ["2.5", 7.5], ["3", 6], ["3.5", 3.5], ["4", 0]]
steps:
  - text: זה הגרף של הגובה. הכדור עולה, ואחר כך יורד.
  - text: מסמנים קו אופקי בגובה 6.
    guide: { y: 6, text: "h = 6" }
  - text: הקו פוגש את הגרף **פעמיים**. פעם בעלייה, ופעם בירידה.
    guide: { y: 6, text: "h = 6" }
    hot: [2, 6]
    label: t = 1  או  t = 3
```

באלגברה זו משוואה **ממעלה שנייה**, כי יש בה `t²`:

- ‏`8t - 2t² = 6`
- ‏`0 = 2t² - 8t + 6`: מעבירים הכול לאגף אחד.
- ‏`t² - 4t + 3 = 0`: מחלקים ב־2.
- נוסחת השורשים, עם `a = 1`, `b = -4`, `c = 3`:
- ‏`t = (4 ± √(16 - 12)) ÷ 2 = (4 ± 2) ÷ 2`
- ‏`t = 3` או `t = 1`.

**שתי התשובות נכונות.** הכדור בגובה 6 מטר אחרי שנייה אחת (בעלייה), ושוב אחרי 3 שניות (בירידה).

> 💡 זהירות בנוסחה: `b = -4`, ולכן `-b = 4`. וכשמציבים בריבוע, `(-4)² = 16`, חיובי.
